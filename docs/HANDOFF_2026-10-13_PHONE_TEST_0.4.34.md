# 知衡 0.4.34：聊天末尾自动跟随

用户反馈每次发送后都需要手动往下翻，另反馈当前模型配置的对话体感已有改善。本轮沿用现有模型配置，修复聊天滚动。

## 原因与调整

原实现只在文字回复完成时同步滚动一次；发送开始使用 `scrollIntoView(nearest)`，未按固定输入框实际位置避让。图片异步完成、照片加载、关联照片栏增高和键盘视口变化时，仅更新布局，没有再次校正聊天末尾。

- 在消息与资料表单之后设置明确的末尾锚点，布局完成后按输入框实际顶部定位，预留约 16px。
- 发消息时恢复跟随；等待、文字回复、图片完成、消息尺寸与输入框尺寸变化后继续校正位置。
- 刷新恢复及切换会话时定位到最新内容。
- 用户主动上翻时暂停跟随，避免阅读历史时被异步结果拉走；“回到最新”按钮或再次发送可恢复跟随。
- 查看原话时保持来源定位；报告弹窗打开时暂停背景滚动，关闭后按既有跟随状态恢复。

主要代码：`app.js`、`app.css`。模型与后端营养分析逻辑未调整，未访问真实 `.data`。
