## 开始人工测试

如果本地服务还在运行，先按原方式停止并重新启动以加载新的 Python 代码，再刷新页面。项目已有入口：

```powershell
powershell -ExecutionPolicy Bypass -File .\start-server.ps1
```

访问 `http://127.0.0.1:8787/`。已有 APK 不会自动包含此次源码修改；本轮没有打包新 APK。

建议按顺序验收：

1. 只描述一个困扰，检查追问是否围绕该问题、理由是否可见。
2. 普通餐食或体重记录后，检查保存回执、刷新后的档案，以及是否被强迫重做问卷。
3. 要求先给初步方案，查看问题、未知项、执行方式、反馈与复盘日期。
4. 在计划页反馈部分完成或困难，查看复盘；选择最低或替代行动，确认生效日期及旧记录未变。
5. 上传照片，分别测试未吃、吃了一部分和修正同一餐，检查是否重复记入。
6. 中断/失败后恢复，检查同一条记录没有重复保存。
