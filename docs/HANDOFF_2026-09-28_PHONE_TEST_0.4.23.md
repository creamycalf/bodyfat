# 知衡 0.4.23：新模型配置与图片任务状态修复

本轮按项目根目录 `config.json` 的当前配置重新打包私人测试 APK。配置为 `https://server.max-tabs.com/v1`，对话模型和图片模型均为 `gpt-5.5`，协议为 `chat_completions`。密钥仍从受控环境变量读取，没有写入本文档。

## 已处理的问题

- 图片任务轮询不再每次清空并重建全部卡片，未变化的缩略图节点会保留，连续上传图片时不会因为轮询造成闪烁。
- 已完成任务的结果读取失败时会自动重试，并提供「查看分析结果」按钮，按钮会重新读取结果并定位到对应图片消息。
- 图片模型返回空内容或无效结构时，任务不会被误报为成功；原图会保留，任务进入明确的重试或失败状态。
- 旧版内置默认地址和旧版 Opus 默认配置会迁移到本包的新默认配置；用户手动保存的其他服务配置保留。

## 验证

- 文本请求使用当前受控环境变量实测连通，返回 `ai_status=connected`。
- 当前服务的两次合成视觉请求均在配置的 75 秒超时内未返回，任务保留原图并进入自动重试状态；这说明中转服务的图片响应速度或图片路由仍需在手机上继续观察，不能把超时说成图片识别成功。
- `tests/qa_repeat_images.mjs`：390px Edge 连续上传两张图片，两份报告均出现；等待轮询后缩略图节点保持；结果读取失败后下一轮能恢复，按钮能定位正确消息。
- Python 回归 277 项通过，记录在 `tmp/tests-0.4.23.log`。
