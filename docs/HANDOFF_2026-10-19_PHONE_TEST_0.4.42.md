# 知衡 0.4.42：长对话记忆、报告检索与 Android 实测

承接 `HANDOFF_2026-10-19_PHONE_TEST_0.4.41.md`。用户要求继续解决实际体验问题，并提供本机雷电模拟器位置。本轮使用隔离虚构资料及公开授权餐食图片；没有读取、修改或打包项目真实 `.data`。

## 实现

- 旧对话的生活条件按当前问题检索，附原消息、日期和“历史自述”状态。覆盖做饭、冷藏、热饭、预算、部分饮食偏好、器械和工作时间；最多六段、两千字。只采本人明确陈述，排除第三方、引用、假设、问句、不保存、禁用、撤销和被更正来源。临床证据仍来自有效档案和记录，不从旧闲聊推断病史。当前档案优先；后来的“有冰箱、可以热饭、可以吃鱼”替换旧限制。
- 明确“忘掉我的冰箱情况”等生活条件撤回会移除实用档案中的相关完整分句，保留独立其他条目，保留有效性历史；在调用模型前落盘，超时也不恢复，并阻止同轮模型补回。若同一分句混有其他条件，则移除整个相关分句，回执明确说明。此路径不删除临床字段。
- 禁用、撤回、更正或撤销来源的旧原文及该轮助手回声，不再经普通历史、上一轮问句或图片最近对话旁路进入模型。当前新输入仍正常处理。历史上下文限制为最近允许的 24 条、合计约 24,000 字符，单条上限 8,000，避免旧实现可达约 144,000 字符的原始历史。
- 记录检索加入有限相关词，如“眼睛检查”可找回“视网膜复查”，并排除未确认、禁用和撤回记录；这是检索关联，不是医学同义诊断。
- 报告按指标别名及所问日期检索，不再被最近几份无关报告挡住；同一指标优先使用自身检查日期。相关报告检索段最多六份、每份四十项，但指定的靠后指标优先；直接选中的图片另有其结构化 review。新结构化保存上限由四十项提高到二百项，并记录遗漏/未识别数量；旧版已截断的报告不能凭升级恢复。归属、单位、日期不明确时保留限制。
- 修复真实测试暴露的“载脂蛋白B 1.3 g/L”被蛋白摄入过滤器误删：只有相关已存报告精确支持的指标、数值/参考范围和质量浓度单位可保留，同句夹带的“每天蛋白质80克”等未经核算建议继续过滤。没有报告依据不豁免。
- 传输不再对确定 DNS/TLS 失败做无效重复请求；自动协议仅在 404/405/501 不兼容时切换，429/503 仍有限重试，预算不足不再等待退避。增加安全耗时诊断，区分本地排队、请求等待、重试间隔。请求等待包含网络、服务端排队和生成，不能称为纯推理时长。
- Android 小屏欢迎页不再被自动追底滚动藏到固定标题下；新空对话回顶部，轮询保留用户主动滚动。有消息、首条发送等待和发送失败仍按原逻辑显示最新内容。

## 剩余限制

1. 正常上传图片仍可能等九十秒以上，文字有四十秒回合及上游 502/504；程序重试优化没有解决服务端等待。
2. 物理手机麦克风、相机和软键盘尚未验收；雷电系统 IME 问题不能当作手机通过。欢迎页小屏空间和快捷卡片可达性仍需改进。
3. 生活记忆是有限维度/规则检索，相关记录和报告有容量限制，不是完整无限语义记忆。24,000 字符预算只约束原始聊天历史，档案、选图 review 和相关报告另有上下文负载。
4. 实际照片营养是宽范围估算；复杂真实检查报告、跨多人归属、长期病程和整套个体医学/运动建议仍缺专业验收。本轮没有自动回写或修复真实旧资料，旧版漏存/误存不能凭升级恢复。
