# 公开源码与本地私人资料

本仓库发布知衡源码、开发文档、虚构测试夹具和离线语音依赖，不提供个人健康资料或含访问密钥的安装包。

- `config.json`、环境凭据、签名密钥、`.data/`、备份、日志、`tmp/`、构建目录及整个 `release/` 均不跟踪；APK/AAB 与生成的 `default_model.json` 另有独立忽略规则。
- 公共 `config.example.json` 仅包含地址与模型占位符。使用者自行配置服务和环境变量，不能从公开仓库取得原开发者的密钥。
- `prototype/lunch.png` 是 AI 生成的虚构演示图，来源说明见 `prototype/README.md`；自动测试使用临时资料和合成夹具。公开图片实测的 CC0 来源记录在对应交接文档中。
- 离线语音模型 ZIP、Vosk/JNA AAR 为构建所需公共依赖；许可、校验清单位于 `android/standalone/app/src/main/assets/voice/`，不能与私人模型接口配置混淆。
- 首次源码发布前已移除需求文档中的真实个人画像及个人健康原话，API/交互示例改为虚构数据；原件备份留在本地忽略目录，未提交。

含远程服务密钥的私人测试包仅供本人测试，不能上传公开仓库或 Releases。公开发行应另行采用服务端凭据方案，并完成多用户隔离和医疗安全评审。
