# 对话连续性修复（源码，尚未打包）

2026-09-22，基于用户对 0.4.5 的反馈。

## 本轮修改

- 普通评估不再因为档案缺项或主题已回答而覆盖模型的正常回复；移除主题结束时固定的阶段总结。模型有正常文字但没有生成计划时，不再追加“尚未生成计划，请重试”。
- 评估候选问题改为提示词参考方向，而非程序强制的一道题。
- 数值过滤只去除命中句子，保留剩余模型文字和原有追问，不再追加“晚餐/加班/零食”的固定问题。整段被过滤、空回复作为明确失败进入现有重试机制，保存回执仍独立呈现。
- 会话追问和评估页使用同一段实际展示的问句归类，不再依据用户最初目标生成一个不对应的后台问题。无法归类时留空，不冒充目标问题。
- “晚餐/加班/零食”等简短回答可以作为目标阻碍反馈，但不会因此推断疾病或补齐其他档案字段。
- 删除此前针对“200斤”硬编码为“100公斤”的回复模板。

## 保留边界

安全拦截、保存失败回执，以及用户明确要求先完善档案却收到过早计划时的兼容流程仍由程序处理。它们不是正常模型追问。主题归类仍为规则辅助，不是完整语义理解。

## 验证

196 项 Python 回归通过，2026-09-22 15:38。新增 `tests/test_conversation_continuity.py` 覆盖多轮追问、主题一致、短回答、数值过滤、无追问、整段被过滤、空回复和超时后事实保存。

旧测试中依赖程序问卷的两个请求明确改为“先完善档案”，保留原有数据保存和撤销断言；主题测试改为提供真实格式的模型追问，不再要求正常回复被模板覆盖。

本轮测试使用临时数据与模型替身，没有改正式健康数据、没有真实模型质量验收，也没有重新生成 APK。现有 0.4.5 安装包不包含本轮修改。
