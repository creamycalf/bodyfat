## 本轮完成

- 浏览器为当前对话生成稳定会话 ID，同一对话的后续问答追加到同一条历史记录；
- “新对话”会清空当前短期消息上下文和会话 ID，但保留长期健康档案；
- 历史页支持搜索完整消息正文、打开完整对话、关闭详情和删除；
- 服务端支持按 `id` 读取完整对话，按 `q` 搜索，并兼容旧的单轮历史数据；
- “23点半睡，7点起”正确计算为 7.5 小时，也支持“睡了6.5小时”；
- 缺少有效时长的睡眠记录不会生成可确认候选，API 也拒绝空值和 0 小时；
- `SECURITY_AND_DATA.md` 已更新请求体限制现状。
- “我的”页面增加完整备份下载和恢复入口；ZIP 包含 JSON、原图及逐文件 SHA-256 清单；
- 恢复前验证路径、版本、大小、JSON 结构、媒体引用和哈希，并先在隔离目录组装后替换 `.data/`。
- 数据目录增加版本元数据；启动时执行幂等迁移，迁移前自动生成回滚备份，高版本数据会阻止旧程序启动；
- 紧急症状规则现在区分否定、假设、既往和已缓解表达，同时保留“否认胸痛但正在呼吸困难”等混合语境的紧急提示。
- 个人资料支持经二次确认清除单个白名单字段；
- 图片根据真实文件头识别 JPEG、PNG、GIF 和 WebP，并拒绝伪装或类型不匹配内容；
- 配置状态接口不再暴露模型名、接口地址或协议，网页只显示是否已配置；
- 增加基础每分钟限流、无正文/查询内容的单行 JSON 日志和启动数据自检；
- 完整备份生成与恢复使用同一大小上限，避免生成无法恢复的备份；
- 移除前端早期重复事件处理器，所有“拍外卖”入口统一打开真实图片选择器；虚假的可关闭照片确认按钮改为“强制开启”。
- 资料编辑页补齐生理性别和手术史；启动脚本会对直接写在 `config.json` 中的 Key 给出迁移提醒；
- 页面与 API 补充 CSP、`no-store`、防 MIME 嗅探、禁止 iframe 嵌入和无来源引用响应头。
- 图片增加宽高和总像素限制，降低小文件声明超大画布造成资源消耗的风险；
- 明确紧急规则扩展到突发卒中征象、昏迷/抽搐、严重过敏、误服/过量和明确自伤风险；自伤风险提示包含 110、120、可信任陪伴者和 12356 心理援助热线。
- 增加可选 `start-supervised.ps1`，在服务异常退出时按有限次数和固定退避重新拉起，不修改系统开机项。
