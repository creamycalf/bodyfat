# 知衡 0.4.18：修复拍照后图片识别 HTTP 413

日期：2026-09-25。用户在知衡 APK 中拍照后能看到照片，但图片识别失败，失败卡片报 `HTTP 413`。这表示模型服务拒绝过大的请求体；照片已由本地应用保存，不代表模型识别成功。

## 根因与修复

- 旧版只按像素（自动识别最多 3000）和本地 10 MB 长度检查照片。JPEG 转成 base64 后会扩大约三分之一，真实拍照容易超过模型服务入口的请求体限制。
- 用合成噪声图和当前图片模型实测：约 84 万字节的图片请求成功，约 136 万字节的请求返回 `AI_HTTP_413`。这与用户报错一致；网关限制可能调整，不将测得阈值当成永久接口规格。
- `image-upload.js` 现在反复调整 JPEG 质量与尺寸，直到整个 data URL 不超过 700 KiB（含 base64）；本地上传 JSON 及图片模型请求均据此收紧。压缩不成时明确提示换普通拍照模式或较小照片。
- 旧 413 任务保留原图，但直接重试仍会发送同一张过大图片。失败卡片明确要求在新版重新选择原图上传，并隐藏无效的原任务重试按钮。其他类型失败仍可重试。
