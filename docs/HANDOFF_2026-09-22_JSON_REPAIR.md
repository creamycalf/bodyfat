# JSON 格式失败修复（源码，尚未重新打包）

## 根因与修复

真实模型返回的 reply 内包含未转义英文引号，外层 JSON 无效。旧解析器继续寻找内部对象，把 decision 误认为完整响应。

- 以 JSON 对象/数组开头但整体非法的内容直接判为格式错误，不再取内部 decision。
- 返回非空但格式错误或缺少 reply 时，自动请求一次模型格式修复。剩余等待时间限制在本轮 85 秒预算内；失败保留明确错误和手动重试入口，不无限重试。
- 无效草稿不先入档，修复后仍走原有事实、证据和安全校验；本地体重保存不重复。
- 移除模型输入中的 allowed_assessment_questions 和完整模板问题，不再用“参考”形式继续诱导模型照抄问卷。只保留自然对话要求及实际评估上下文。

## 验证

- 199 项回归通过，包含未转义引号、修复成功/连续失败、体重唯一保存与无模板提示词断言。
- 用 0.4.6 APK 内相同模型配置，在临时目录运行新源码两轮真实对话：“你好，我体重200斤，想减肥怎么办” → “38岁，172厘米，男生”。两轮均 connected、ai_error=null，体重记录始终一条。
- 真实模型仍出现一轮询问多个问题的表达，说明对话节奏质量未完全满足“一次一个问题”的要求；不把链路修复宣称为所有内容质量已通过。
- 这是电脑环境真实模型验证，不是安卓真机验证。本轮未生成新 APK，0.4.6 不包含本次修改；正式健康数据未改动。
