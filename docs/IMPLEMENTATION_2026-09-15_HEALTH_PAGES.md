# 计划、档案与看板页面更新

依据用户确认的健康工作区样稿，正式界面使用对话、看板、计划、档案四个菜单。

- 看板显示实际体重记录、今日摄入估算范围、今日安排及打卡进度。无饮食记录显示未记录。
- 当前计划集中呈现，执行事项可直接打卡完成、部分完成、跳过、延期和撤回。对话反馈使用同一个 task_id。
- 历史计划及版本在计划菜单折叠展示，包含该版本的打卡记录，不提供旧版本重新启用入口。
- 饮食事项支持 meal_options，分为自己做（菜名、食材、做法）和外卖（搭配、搜索词、备注）。既有计划没有该结构时提供获取做法/搜索建议入口，原有详细安排仍可展开查看。
- 做法入口携带准确的计划版本、事项与模式，结合档案向已配置模型请求说明。服务端强制该请求只返回解释，忽略模型返回的计划、档案、健康记录、页面与打卡写入。
- 档案按身体情况、目标与饮食偏好、生活规律、健康背景分组；来源、编辑、实际记录及原图功能保留。
- 聊天正文安全处理换行和加粗，补充页面模块收起展示，既有自动摘要不重复展示。
