# 知衡 0.4.13：外卖可得性边界修复测试包

日期：2026-09-24。此版本继续收尾 P0，并把计划生成阶段的外卖可得性边界落实到程序校验。供用户本人覆盖安装测试；尚未进行真机验收，也不代表临床建议已验证。

## 本轮修复

- 如果用户没有提供真实菜单，模型即使返回“附近清蒸鲤鱼”或类似具体菜品，计划保存前也会被程序降级为“待核对的外卖类别”，只保留通用搜索方向和菜单、过敏原、营业状态、送达时间、份量核对提示。
- 计划页面将此状态显示为“外卖搜索方向 · 尚未核对菜单”，避免把搜索建议误解为附近可买的商家或库存。
- 继续保留 0.4.12 的无菜单普通问答回退、减重目标单项追问、当天餐次判断、可选起步引导和第三天复盘。
