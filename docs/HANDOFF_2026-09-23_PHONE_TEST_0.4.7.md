# 知衡 0.4.7 手机测试版交接

本版安装包：`release/android-0.4.7/Zhiheng-0.4.7-standalone-test.apk`。Android 8.0 及以上，包名 `cn.zhiheng.mobile`，版本码 15，使用与 0.4.6 相同的本地测试签名。安装包不内嵌模型密钥、配置文件或健康数据。覆盖安装同签名旧版时应保留 App 数据，但更新前仍建议在旧版导出备份；不要先卸载。

## 本轮完成

- 咨询与记忆沿用第一阶段的已知/未知分离、资料摘要核对、可靠保存与失败恢复。
- 餐食图片报告可逐项改食物、可食重量、每 100g 或每份营养值、来源、份数，预览后重算；整道菜与组成可排除重复计数。模型估计和用户提供的标签/参考值分开标示，常吃标签值可本机复用。
- 图片分析和报告编辑本身不代表已吃。输入本人实际食用份数并明确勾选后才保存或修正同一条摄入记录；0 份可撤回。已有摄入记录的照片再次改报告，须重新确认食用份数。最近一次修正可撤销。
- 阶段复盘呈现行动反馈、饥饿感、执行困难、睡眠、活动及体重记录；缺项明确写未知，短期体重波动不触发限制。调整保留版本和依据。
- 餐单支持结构化购物清单及复制，购物建议与实际摄入分离；已有过敏信息参与选项校验。

## 验证与边界

隔离 Python 回归 219 项通过；390px Edge 端到端流程覆盖照片压缩、报告修改、来源保存、明确食用、错误提示。Android 离线 `assembleRelease` 成功；已核对版本、签名和 APK 资源清单。未做真机运行、真实中餐照片准确率评估、长期咨询或临床验证。

尚未接入经授权核验的外部食物数据库，也没有把模型估计冒充查库值。中文混合菜、油酱、品牌标签及生熟重量仍需用户核对；数据库/真实照片核验集需另定数据来源与授权。该包是手机测试版，不是医疗或营养精度认证版本。

首次安装或旧版未保存 AI 设置时，在 App 的“AI 设置”中填入 HTTPS 模型接口、模型名称和自己的密钥；本包没有“内置测试模型”可恢复。设置留在手机加密存储；AI 对话和图片分析会把相关内容发往用户选定的模型服务，本地记录可离线使用。

建议手机试验：覆盖安装后先看旧记录；配置并测试模型；依次试普通咨询、拍照后补充意图、核对报告但不记账、确认只吃一部分、再次修正并撤销、复盘和购物清单。若遇异常，反馈手机系统版本、操作顺序、屏幕截图和错误码，勿发送密钥或未脱敏健康数据。
