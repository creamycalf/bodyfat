# 知衡 0.4.26：图片分析独立超时预算

用户手机截图显示 AI_TIMEOUT，原图已保存并等待自动重试。旧版手机请求固定 75 秒，外层总预算 90 秒，文字与视觉共用预算。

本次将视觉读响应超时独立设为 180 秒，视觉外层总预算为 205 秒（为连接等开销留余量）。显式传入更短总预算仍有效；文字预算不变。手机启动时会规范化已有配置，因此覆盖安装后也能采用新视觉预算，无须重新填 Key。服务本身持续不可用时仍可能超时，并沿用原图保留和有限重试逻辑。
