# 模型接入后稳定性改造（2026-09-02）

## 已完成

- 使用 `claude-opus-4-6` 和 OpenAI-compatible `/chat/completions` 完成真实文本与图片调用。
- 增加模型请求 ID、耗时、状态、并发限制、有限重试和安全错误分类。
- 胸痛、呼吸困难等紧急关键词由本地规则立即响应，不等待远程模型。
- 结构化候选数据统一为数组，并归一化睡眠小时与体重公斤字段。
- 前端增加发送中状态、按钮防重复、超时、模型降级原因和图片失败提示。
- 确认写入后即时刷新今日看板和健康档案。
- 睡眠和体重候选字段可在确认前直接编辑，并在前端再次校验合理范围。
- 多条候选记录使用一次原子批量确认；写入后提供 120 秒、一次性的整批撤销令牌。
- 看板体重趋势改为近 14 日已确认体重记录实时计算，不再使用演示数值。
- 模型上下文只读取白名单档案字段和最近 12 条已确认记录，并限制最近对话为 6 条。
- 移除首屏、档案、看板和个人页中的虚构演示健康数据；未接入能力明确显示为未连接或数据不足。
- 档案中的睡眠和体重支持单条修改，所有记录支持二次确认后单条删除。
- 今日重点、行动步骤和依据由已确认记录确定性生成；没有数据时不再猜测热量或活动建议。
- 未确认的原始媒体按 `delete_original_after_days` 自动清理，且只允许删除媒体目录内的文件；已确认媒体保留。
- 对话历史使用本地确定性摘要展示，可单独删除；删除对话不会连带删除已确认健康档案。
- 每条健康记录都可切换是否参与模型记忆；模型只接收已确认且允许记忆的最近 12 条记录，并剔除内部来源字段。
- 图片分析后必须明确选择“确认保留”或“不保留”，个人页可查看保存状态并永久删除原图。
- 图片上传仅接受 JPEG、PNG、WebP 和 GIF，媒体 ID 改为不可预测的随机标识。
- 长期记忆从“固定最近记录”升级为本地相关性检索：记录类型、关键词、时间共同排序，单次最多返回 12 条。
- 每次对话响应返回实际命中的记录 ID、类型和命中原因，前端会显示“本次参考记忆”。
- “我的”页面增加健康记忆搜索，可直接查看匹配记录及“类型一致、关键词、近14天”等依据。
- 个人资料已改为真实可编辑表单，支持称呼、年龄、身高、目标、偏好、疾病状况、过敏和用药，并在服务端校验范围与长度。
- 数据文件采用临时文件替换方式保存，减少写入中断导致的 JSON 损坏。
- 限制本地 API 跨域来源；清空数据时同步删除原始媒体文件。
- 示例配置不再包含 Key；本地凭据文件已被 `.gitignore` 排除。

## 验证方式

```powershell
python -m unittest discover -s tests -v
powershell -ExecutionPolicy Bypass -File .\start-server.ps1
```

浏览器验收包括：发送加载状态、真实模型回复、候选字段编辑、批量确认、撤销、真实趋势刷新、档案展示和控制台错误检查。

当前自动化测试共 12 项，覆盖协议与请求头、鉴权错误、候选数据归一化、记录校验、真实 14 日趋势、安全规则、记忆白名单/开关与检索排序、对话摘要、资料校验、数据建议和媒体清理边界。
