### 服务和模型

```powershell

Invoke-RestMethod http://127.0.0.1:8787/api/config-status

$body = @{ text = '请只回复：模型连接正常'; messages = @() } | ConvertTo-Json
```

## 3. 浏览器验收清单

### 对话与确认

- 页面显示 AI 已配置；
- 发送时按钮禁用并显示分析中；
- 回复成功或明确显示降级原因；
- 睡眠和体重候选可修改；
- 多条候选一次写入；
- 写入后看板和档案立即刷新；
- 120 秒内可以整批撤销。

### 档案与看板

- 无数据时不显示虚构体重、热量或运动建议；
- 两次近 14 日体重后绘制真实趋势；
- 单条睡眠/体重可修改；
- 所有记录可二次确认删除；
- 记忆开关关闭后，搜索和对话不再命中该记录；
- 今日建议显示数据依据。

### 个人资料和记忆

- 资料保存后刷新仍能回显；
- 非法年龄或身高被拒绝；
- “最近体重”等查询只显示相关记录；
- 命中项显示类型、关键词或时间依据；
- 对话回复显示本次参考记忆。
- 有来源 ID 的资料或记录可点击“查看原话”定位到对应对话；旧迁移资料明确显示为既有资料；
- 计划依据记录被删除或关闭记忆后显示复核提醒，不静默重算或篡改原计划；
- 基本资料不足并请求制定方案时显示“填写表单”和“文字/语音”两个入口；
- 每个表单字段均可跳过，空白不覆盖已有资料；
- 只填写一个字段也能保存，刷新后再次打开可正确预填；
- 选择不用表单后聚焦输入框，当前页面会话不重复强制弹表单；
- 表单已保存的体重不再出现第二次候选确认。

### 对话历史和媒体

- 历史页只显示真实本地对话摘要；
- 删除对话不影响健康档案；
- 上传前需要确认发送给 AI；
- 分析后在档案页显示摘要、核对问题和可编辑候选；体重及检查项目的常见值使用带中文标签的普通字段，候选不会自动写入；
- 确认所选候选后记录与原图状态同时保存，重复提交不会重复写入；
- 也可以仅保留或立即删除原图；
- 个人页显示原图状态；
- 不支持的图片格式被拒绝。

## 4. 隔离测试原则

涉及新增、修改或删除时，应复制 `server.py`、`index.html` 和无密钥示例配置到临时目录，用另一个端口运行，避免污染正式 `.data/`。测试结束后停止精确端口对应的进程，验证临时目录路径后再删除。

正式环境只做只读检查、安全规则测试和不写档案的模型连通测试。
