# 知衡 0.4.21：聊天节奏与资料整理分离

用户授权改进自然对话体验。本版未换模型，未读取或打包生产健康资料。结论：程序边界修复完成，连续对话有改善，但模型仍会误读事实、过多追问，不能宣布咨询质量已验收。

## 实现

- 表达减重目标不再自动进入正式评估。会话保存聊天/评估模式；“先聊聊”“先解释”“暂停建档”可中断流程，普通继续不会恢复问卷，明确请求方案或继续评估可恢复。正式方案仍须准备度和摘要确认。
- 解释意图跨轮保留，用户要建议或换话题时更新；拒答仍保持未知。后台可记录主动提供的事实，不要求先补齐档案。
- 聊天模式先请求自然文字，再单独请求当前用户原话的事实提取。提取步骤不接收模型回复作为证据，不能提交方案或页面变更。整理失败保留聊天回复并显示回执。当前两次请求仍串行完成后返回，尚非流式显示；第二次有最多25秒预算，因此可能增加延迟和请求量。
- 普通聊天绕过正式评估的模板替换。模型自作主张返回的计划与页面变更被清空，即使已有执行计划也不能越权修改。
- 发送到模型服务前合并连续文本 system 消息，保留规则和背景。单题对照中两条 system 的回复较长且多问，合并后为两句；后续两组对话有所改善。网关内部行为未验证，不能断言其丢弃第一条 system，也不能把全部改进归于单一变化。
- 保留 JSON 回复兼容、营养数字校验、拒答过滤、正式评估与危险计划检查。

## 验证

- 276 项 Python 回归通过，日志 `tmp/tests-0.4.21.log`。新增独立回复/提取、提取失败、意图切换、已有计划不被聊天修改及实际请求 system 合并检查。旧问卷测试改为明确申请评估后仍检查原安全边界；新的纯目标测试检查不自动追问。
- 最终原场景八轮 `tmp/dialogue-original-merged-0.4.21.json`，新场景八轮 `tmp/dialogue-pacing-merged-0.4.21.json`，均 connected 并通过预设拒答/不存计划/事实字段检查。每轮正常两次模型调用。这些检查不认证回答正确。
- 新场景包含称重焦虑、家庭聚餐、拒答、只解释、更正、继续、换到食品标签及索要小建议。更正后能停住，换话题未拉回问卷；原场景开场改为围绕坚持困难，不再被程序改为年龄问卷。最终样本未再出现个人低血糖时间线。
- 尚有问题：原场景把九点下班说成九点到家；假设不吃晚餐便一天只吃一顿，未核对早餐；多问问题、解释过长仍发生；新场景要一个建议仍给两个。部分心理/生理解释过度确定，事实归属混合句依然可能不保存，口头“更正”不等于持久记录完成。
- 中间报告（文件名含 final 也包括合并 system 之前的版本）不能当最终验收：`dialogue-pacing-0.4.21.json`、`dialogue-pacing-0.4.21-final.json`、`dialogue-original-0.4.21-final.json`、`dialogue-pacing-split-0.4.21.json`。其中仍有格式错误和严重过度推断。
- 本轮未做新的浏览器视觉验收或真机操作；UI 未改动，Android 系统功能与用户主观体感待手机测试。
